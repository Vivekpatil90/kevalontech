# Kevalon Technology — Website

Premium dark-themed React + Vite website for Kevalon Technology.

## Stack
React 18, Vite, React Router DOM, Tailwind CSS, Framer Motion, GSAP, Lenis, Swiper, React Icons.

## Setup
```bash
npm install
npm run dev
npm run build
```

## Structure
- `src/components` — reusable UI (Navbar, Footer, Loader, Cursor, MagneticButton, etc.)
- `src/pages` — Home, About, Services, Portfolio, Careers, Contact
- `src/layouts` — RootLayout with sticky navbar + footer
- `src/routes` — AppRoutes with animated transitions
- `src/hooks` — custom hooks (useLenis, useMagnetic)
- `src/utils` — shared data & constants
